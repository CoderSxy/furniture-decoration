## 3. 用户隐私保护指引（可粘贴）

路径：微信公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引**。

开发者处理的信息勾选摄像头、选中的照片或视频信息、以及用户标识（openid）：

### 3.1 摄像头

- **信息类型：** 摄像头（对应接口用途文案须含「访问你的摄像头」）
- **使用目的：**

```
用于量房时识别地面并测量房间长宽。仅在用户主动进入「采集房型」时调用。登录后测量结果（长 / 宽 / 层高数字）会同步到自建服务器；参考照片和录像不上云，不保存录像。
```

- **使用场景：** 方案详情 → 量房阶段 → 「采集房型」→ VisionKit 取景测量

### 3.2 选中的照片或视频信息

- **信息类型：** 选中的照片或视频信息（`chooseMedia`，仅相册图片）
- **使用目的：**

```
当设备不支持 VisionKit、或用户未授权摄像头时，允许从相册选择最多 3 张房间参考图，方便手填长宽高。图片只保存在本机临时路径，不会上传。
```

- **使用场景：** 「采集房型」降级表单 → 选择参考图

### 3.3 明确不收集

不收集手机号、位置、通讯录、身份证、好友关系、支付信息。登录只用 openid。

存储：收藏 / 方案 / 预算 / 房型尺寸 / AI 选品快照写入本机 `Taro.setStorageSync`（`fd:*`），登录后同步到自建 HTTPS 服务器。扫描参考图仍只留本机，不上云。清理小程序数据会丢失本机副本。

代码在调用相机前走 `requirePrivacyAuthorize` 与 `scope.camera`；拒绝则手填，不强制授权。

### 3.4 用户标识（openid）

- **信息类型：** 用户标识（通过 wx.login 换取的 openid，仅保存在自建服务器）
- **使用目的：** 识别同一微信用户并同步收藏、方案、预算、房型尺寸与 AI 选品快照。不收集手机号、昵称或头像。

## 5. 本地打包（Node 22）

在仓库根目录，使用 Node.js `>=22.23.4 <23` 与 pnpm 10.x：

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm --dir server test
pnpm build:weapp
```

产物在 `dist/`。预览 3D 请用这次生产构建，不要只靠 `pnpm dev:weapp` 热更新判断 xr-frame。

本地后端：`pnpm --dir server install` 后配置 `server/.env`（变量名见 `server/.env.example`），再 `pnpm --dir server dev`。小程序侧在未跟踪的 `.env` 设置 `TARO_APP_API_BASE_URL`（无尾斜杠）。不要在命令或仓库里粘贴 AppSecret、`.env` 真值或模型 Key。
