# M0 工程底座 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在仓库根目录搭好 Taro 4 微信小程序工程底座：四 Tab 壳、六个空 Zustand store、主题 token、扫描/预览分包占位页，并能 `dev:weapp` / `build:weapp` / `typecheck`。

**Architecture:** 用官方 `@tarojs/cli@4.3.2` React + TypeScript + Vite 模板在临时目录初始化，再把文件合并进仓库根目录（保留已有 `docs/`）。主包只放四个 Tab；`packageScan` 与 `packagePreview` 放空占位页，避免 M4/M5 再改主包配置。状态层六个 store 只导出空初始值，页面各读一个字段，确保 Zustand 进入编译图。

**Tech Stack:** Taro 4.3.x、React 18（模板默认，禁止 React 19）、TypeScript、Vite、Zustand 5、pnpm、Node.js `>=22.23.4 <23`、目标端仅 weapp。

## Global Constraints

- 客户端：Taro 4 + React 18（template default, NOT React 19）+ TypeScript + Vite + Zustand。
- 包管理器：pnpm；`package.json` `engines.node` 为 `>=22.23.4 <23`（Node 22.23.4 为 2026-11-03 的当前 LTS 安全 patch）。
- 目标端：weapp only，不维护 H5 / 其他小程序端。
- `config/dev.ts` 必须设置 `mini.debugReact: true`（规避 Zustand 5 + Taro Vite 的 `taro.react_production_min.create is not a function`）。
- Tab 路径：`pages/catalog/index`、`pages/plans/index`、`pages/budget/index`、`pages/mine/index`；文案「选品 / 方案 / 预算 / 我的」。
- 空 store：`catalogStore`、`favoriteStore`、`planStore`、`budgetStore`、`scanStore`、`uiStore`。
- 主题 token 放 `src/theme/tokens.ts`，经 `src/app.scss` CSS 变量落地。
- 分包占位：`packageScan`、`packagePreview`。
- 密钥不进仓库；`project.config.json` 使用占位 `appid` `touristappid`；`.gitignore` 包含 `project.private.config.json`。
- 不部署、不提交小程序审核、不把体验版当正式发布。
- UI 文案简体中文；代码标识符英文。
- 不得删除 `docs/superpowers/` 下已有设计文档。
- 规格来源：`docs/superpowers/specs/2026-11-03-furniture-decoration-mvp-design.md`（只实现该文档的 **M0**，不要做 M1–M5 业务）。

生成 81×81 PNG（未激活灰、激活用主色）：

```bash
python3 - <<'PY'
from pathlib import Path
import struct, zlib

def png(path: Path, rgb):
    w = h = 81
    r, g, b = rgb
    raw = b''.join(b'\x00' + bytes([r, g, b]) * w for _ in range(h))
    def chunk(tag, data):
        return struct.pack('>I', len(data)) + tag + data + struct.pack('>I', zlib.crc32(tag + data) & 0xffffffff)
    ihdr = struct.pack('>IIBBBBB', w, h, 8, 2, 0, 0, 0)
    data = b'\x89PNG\r\n\x1a\n' + chunk(b'IHDR', ihdr) + chunk(b'IDAT', zlib.compress(raw)) + chunk(b'IEND', b'')
    path.write_bytes(data)

root = Path('/workspace/src/assets/tab')
root.mkdir(parents=True, exist_ok=True)
idle = (122, 113, 104)      # textMuted
active = (196, 92, 38)      # primary
for name in ('catalog', 'plans', 'budget', 'mine'):
    png(root / f'{name}.png', idle)
    png(root / f'{name}-active.png', active)
print('wrote', list(p.name for p in sorted(root.iterdir())))
PY
```
