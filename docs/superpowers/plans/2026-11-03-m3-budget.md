# M3 成本预算进度条 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 M0–M2 Taro weapp 上交付当前方案预算页：按面积生成总额、四类目占用条、由阶段推导的进度、超支提示、收藏未入方案提示、无当前方案空态，以及「我的」重置 mock。

**Architecture:** 不重做脚手架，不改 `Budget` / `BudgetCategory` / `Plan` 类型。预算与方案一对一。纯函数 `buildBudget(plan, products)` 是展示与落盘的唯一公式：`totalFen = round(areaM2 * 80000)`；`furniture` 只加总当前方案 `productIds` 对应商品的 `priceFen`（收藏未入方案不计）；`material = round(totalFen * 0.35)`；`labor = round(totalFen * 0.25)`；`other = max(0, totalFen - furniture - material - labor)`。阶段进度不入库，由 `stage` 映射 15 / 40 / 75 / 100。`budgetStore` 把 `Record<planId, Budget>` 写入 `fd:budgets`。预算页始终用 `buildBudget` 现算，切 Tab 即读 `planStore`；新建 / 增删商品 / 启动 hydrate 后调用 `ensureForPlan(s)` 写快照。`planStore` 不 import `budgetStore`。扫描仍无业务写入，只补 `fd:scans` 的 hydrate / reset，供重置 mock 清四类 key。

**Tech Stack:** Taro 4.3.2、React 18.3.1、TypeScript、Vite、Zustand 5、pnpm、Node.js `>=22.23.4 <23`、目标端仅 weapp。不新增 npm 依赖。

### Task 3: 预算公式与展示纯函数

**Files:**
- Create: `src/utils/budget.ts`
- Create: `tests/budget.test.ts`

**Interfaces:**
- Consumes: `Budget`、`BudgetCategory`、`Plan`、`PlanStage`、`Product`、`FavoriteRecord`
- Produces:
  - `AREA_BUDGET_FEN_PER_M2 = 80000`（800 元/㎡ 的分）
  - `MATERIAL_RATIO = 0.35`
  - `LABOR_RATIO = 0.25`
  - `STAGE_PROGRESS_PERCENT: Record<PlanStage, number>` = `{ measure: 15, design: 40, construct: 75, accept: 100 }`
  - `computeTotalFen(areaM2: number): number` → `Math.round(areaM2 * 80000)`；`areaM2` 非有限或 `<= 0` 时返回 `0`
  - `computeFurnitureFen(productIds: readonly string[], products: readonly Product[]): number`：按 `productIds` 顺序把能在 `products` 里找到的 `priceFen` 相加；找不到的 id 跳过；**不**读收藏
  - `computeMaterialFen(totalFen: number): number` → `Math.round(totalFen * 0.35)`
  - `computeLaborFen(totalFen: number): number` → `Math.round(totalFen * 0.25)`
  - `computeOtherFen(totalFen, furnitureFen, materialFen, laborFen): number` → `Math.max(0, totalFen - furnitureFen - materialFen - laborFen)`
  - `buildBudget(plan: Pick<Plan, 'id' | 'areaM2' | 'productIds'>, products: readonly Product[]): Budget`
  - `occupancyPercent(spentFen: number, totalFen: number): number`：`totalFen <= 0` 或任一参数非有限 → `0`；`spentFen <= 0` → `0`；否则 `Math.min(100, Math.round((spentFen / totalFen) * 100))`
  - `isFurnitureOverspent(budget: Pick<Budget, 'totalFen' | 'spentByCategory'>): boolean` → `furniture > totalFen`
  - `stageProgressPercent(stage: PlanStage): number` → 查 `STAGE_PROGRESS_PERCENT`
  - `countFavoritesNotInPlan(favorites: readonly FavoriteRecord[], productIds: readonly string[]): number`：收藏 `productId` 不在 `productIds` 里的件数（按收藏记录计，不要求商品仍存在于 mock）
  - `favoritesNotInPlanTip(count: number): string | null`：`count > 0` → `` `收藏中有 ${count} 件尚未加入当前方案` ``，否则 `null`

// src/utils/budget.ts
import type { Budget, FavoriteRecord, Plan, PlanStage, Product } from '../types/domain'

export const AREA_BUDGET_FEN_PER_M2 = 80000
export const MATERIAL_RATIO = 0.35
export const LABOR_RATIO = 0.25

export const STAGE_PROGRESS_PERCENT: Record<PlanStage, number> = {
  measure: 15,
  design: 40,
  construct: 75,
  accept: 100,
}

export function computeTotalFen(areaM2: number): number {
  if (!Number.isFinite(areaM2) || areaM2 <= 0) return 0
  return Math.round(areaM2 * AREA_BUDGET_FEN_PER_M2)
}

export function computeFurnitureFen(
  productIds: readonly string[],
  products: readonly Product[],
): number {
  const byId = new Map(products.map((item) => [item.id, item]))
  let sum = 0
  for (const id of productIds) {
    const product = byId.get(id)
    if (product) sum += product.priceFen
  }
  return sum
}

export function computeMaterialFen(totalFen: number): number {
  return Math.round(totalFen * MATERIAL_RATIO)
}

export function computeLaborFen(totalFen: number): number {
  return Math.round(totalFen * LABOR_RATIO)
}

export function computeOtherFen(
  totalFen: number,
  furnitureFen: number,
  materialFen: number,
  laborFen: number,
): number {
  return Math.max(0, totalFen - furnitureFen - materialFen - laborFen)
}

export function buildBudget(
  plan: Pick<Plan, 'id' | 'areaM2' | 'productIds'>,
  products: readonly Product[],
): Budget {
  const totalFen = computeTotalFen(plan.areaM2)
  const furniture = computeFurnitureFen(plan.productIds, products)
  const material = computeMaterialFen(totalFen)
  const labor = computeLaborFen(totalFen)
  const other = computeOtherFen(totalFen, furniture, material, labor)
  return {
    planId: plan.id,
    totalFen,
    spentByCategory: {
      furniture,
      material,
      labor,
      other,
    },
  }
}

export function occupancyPercent(spentFen: number, totalFen: number): number {
  if (!Number.isFinite(spentFen) || !Number.isFinite(totalFen) || totalFen <= 0) return 0
  if (spentFen <= 0) return 0
  return Math.min(100, Math.round((spentFen / totalFen) * 100))
}

export function isFurnitureOverspent(
  budget: Pick<Budget, 'totalFen' | 'spentByCategory'>,
): boolean {
  return budget.spentByCategory.furniture > budget.totalFen
}

export function stageProgressPercent(stage: PlanStage): number {
  return STAGE_PROGRESS_PERCENT[stage]
}

export function countFavoritesNotInPlan(
  favorites: readonly FavoriteRecord[],
  productIds: readonly string[],
): number {
  const inPlan = new Set(productIds)
  return favorites.filter((item) => !inPlan.has(item.productId)).length
}

export function favoritesNotInPlanTip(count: number): string | null {
  if (count <= 0) return null
  return `收藏中有 ${count} 件尚未加入当前方案`
}

// src/stores/budgetStore.ts
import { create } from 'zustand'
import { BUDGETS_STORAGE_KEY } from '../constants/storageKeys'
import type { Budget, BudgetCategory, Plan, Product } from '../types/domain'
import { buildBudget } from '../utils/budget'
import { readJSON, writeJSON } from '../utils/storage'

const CATEGORIES: readonly BudgetCategory[] = ['furniture', 'material', 'labor', 'other']

function isNonNegativeFinite(value: unknown): value is number {
  return typeof value === 'number' && Number.isFinite(value) && value >= 0
}

function parseBudget(key: string, input: unknown): Budget | null {
  if (input == null || typeof input !== 'object') return null
  const row = input as Record<string, unknown>
  if (typeof row.planId !== 'string' || row.planId.length === 0) return null
  if (row.planId !== key) return null
  if (!isNonNegativeFinite(row.totalFen)) return null
  const spentRaw = row.spentByCategory
  if (spentRaw == null || typeof spentRaw !== 'object') return null
  const spent = spentRaw as Record<string, unknown>
  const spentByCategory = {} as Record<BudgetCategory, number>
  for (const category of CATEGORIES) {
    if (!isNonNegativeFinite(spent[category])) return null
    spentByCategory[category] = spent[category]
  }
  return {
    planId: row.planId,
    totalFen: row.totalFen,
    spentByCategory,
  }
}

export function parsePersistedBudgets(input: unknown): Record<string, Budget> {
  if (input == null || typeof input !== 'object' || Array.isArray(input)) return {}
  const result: Record<string, Budget> = {}
  for (const [key, value] of Object.entries(input as Record<string, unknown>)) {
    const budget = parseBudget(key, value)
    if (budget) result[key] = budget
  }
  return result
}

function persist(budgets: Record<string, Budget>): void {
  writeJSON(BUDGETS_STORAGE_KEY, budgets)
}

export type BudgetState = {
  budgets: Record<string, Budget>
  hydrate: () => void
  ensureForPlan: (
    plan: Pick<Plan, 'id' | 'areaM2' | 'productIds'>,
    products: readonly Product[],
  ) => Budget
  ensureForPlans: (
    plans: Array<Pick<Plan, 'id' | 'areaM2' | 'productIds'>>,
    products: readonly Product[],
  ) => void
  reset: () => void
}

export const useBudgetStore = create<BudgetState>((set, get) => ({
  budgets: {},
  hydrate: () => {
    set({ budgets: parsePersistedBudgets(readJSON<unknown>(BUDGETS_STORAGE_KEY, null)) })
  },
  ensureForPlan: (plan, products) => {
    const budget = buildBudget(plan, products)
    const budgets = { ...get().budgets, [plan.id]: budget }
    persist(budgets)
    set({ budgets })
    return budget
  },
  ensureForPlans: (plans, products) => {
    const budgets: Record<string, Budget> = {}
    for (const plan of plans) {
      budgets[plan.id] = buildBudget(plan, products)
    }
    persist(budgets)
    set({ budgets })
  },
  reset: () => {
    persist({})
    set({ budgets: {} })
  },
}))

export function selectBudgetByPlanId(state: BudgetState, planId: string): Budget | undefined {
  return state.budgets[planId]
}

// src/stores/planStore.ts
import { create } from 'zustand'
import { ROOM_CREATE_OPTIONS, STAGE_ORDER } from '../constants/labels'
import { PLANS_STORAGE_KEY } from '../constants/storageKeys'
import type { Plan, PlanStage, RoomType } from '../types/domain'
import {
  canAdvanceStage,
  createPlanId,
  nextStage,
  validateCreatePlan,
  type CreatePlanError,
  type CreatePlanInput,
} from '../utils/plans'
import { readJSON, writeJSON } from '../utils/storage'

export type PersistedPlans = {
  plans: Plan[]
  activePlanId: string | null
}

export type AddProductResult = 'added' | 'duplicate' | 'no-active-plan'

export type CreatePlanResult =
  | { ok: true; plan: Plan }
  | { ok: false; reason: CreatePlanError }

function isRoomType(value: unknown): value is RoomType {
  return typeof value === 'string' && (ROOM_CREATE_OPTIONS as readonly string[]).includes(value)
}

function isPlanStage(value: unknown): value is PlanStage {
  return typeof value === 'string' && (STAGE_ORDER as readonly string[]).includes(value)
}

function parseProductIds(input: unknown): string[] {
  if (!Array.isArray(input)) return []
  const ids: string[] = []
  for (const item of input) {
    if (typeof item !== 'string' || item.length === 0) continue
    if (!ids.includes(item)) ids.push(item)
  }
  return ids
}

function parsePlan(input: unknown): Plan | null {
  if (input == null || typeof input !== 'object') return null
  const row = input as Record<string, unknown>
  if (typeof row.id !== 'string' || row.id.length === 0) return null
  if (typeof row.title !== 'string' || row.title.trim().length === 0) return null
  if (!isRoomType(row.roomType)) return null
  if (typeof row.areaM2 !== 'number' || !Number.isFinite(row.areaM2) || row.areaM2 <= 0) return null
  if (!isPlanStage(row.stage)) return null
  if (typeof row.createdAt !== 'string' || row.createdAt.length === 0) return null
  if (typeof row.updatedAt !== 'string' || row.updatedAt.length === 0) return null
  const productIds = parseProductIds(row.productIds)
  const plan: Plan = {
    id: row.id,
    title: row.title,
    roomType: row.roomType,
    areaM2: row.areaM2,
    stage: row.stage,
    productIds,
    createdAt: row.createdAt,
    updatedAt: row.updatedAt,
  }
  if (typeof row.coverProductId === 'string' && row.coverProductId.length > 0) {
    plan.coverProductId = row.coverProductId
  }
  return plan
}

export function parsePersistedPlans(input: unknown): PersistedPlans {
  if (input == null || typeof input !== 'object' || Array.isArray(input)) {
    return { plans: [], activePlanId: null }
  }
  const row = input as { plans?: unknown; activePlanId?: unknown }
  const plans = Array.isArray(row.plans)
    ? row.plans.map(parsePlan).filter((item): item is Plan => item != null)
    : []
  const activePlanId =
    typeof row.activePlanId === 'string' && plans.some((item) => item.id === row.activePlanId)
      ? row.activePlanId
      : null
  return { plans, activePlanId }
}

function persist(plans: Plan[], activePlanId: string | null): void {
  const payload: PersistedPlans = { plans, activePlanId }
  writeJSON(PLANS_STORAGE_KEY, payload)
}

export type PlanState = {
  plans: Plan[]
  activePlanId: string | null
  hydrate: () => void
  createPlan: (input: CreatePlanInput) => CreatePlanResult
  setActivePlanId: (planId: string) => void
  addProductToActivePlan: (productId: string) => AddProductResult
  removeProductFromPlan: (planId: string, productId: string) => void
  advanceStage: (planId: string) => boolean
  reset: () => void
}

export const usePlanStore = create<PlanState>((set, get) => ({
  plans: [],
  activePlanId: null,
  hydrate: () => {
    const parsed = parsePersistedPlans(readJSON<unknown>(PLANS_STORAGE_KEY, null))
    set(parsed)
  },
  createPlan: (input) => {
    const reason = validateCreatePlan(input)
    if (reason !== 'ok') return { ok: false, reason }
    const now = new Date().toISOString()
    const plan: Plan = {
      id: createPlanId(),
      title: input.title.trim(),
      roomType: input.roomType,
      areaM2: input.areaM2,
      stage: 'measure',
      productIds: [],
      createdAt: now,
      updatedAt: now,
    }
    const plans = [...get().plans, plan]
    persist(plans, plan.id)
    set({ plans, activePlanId: plan.id })
    return { ok: true, plan }
  },
  setActivePlanId: (planId) => {
    if (!get().plans.some((item) => item.id === planId)) return
    persist(get().plans, planId)
    set({ activePlanId: planId })
  },
  addProductToActivePlan: (productId) => {
    const { plans, activePlanId } = get()
    if (activePlanId == null) return 'no-active-plan'
    const current = plans.find((item) => item.id === activePlanId)
    if (!current) return 'no-active-plan'
    if (current.productIds.includes(productId)) return 'duplicate'
    const productIds = [...current.productIds, productId]
    const coverProductId = current.coverProductId ?? productId
    const next = plans.map((item) =>
      item.id === activePlanId
        ? { ...item, productIds, coverProductId, updatedAt: new Date().toISOString() }
        : item,
    )
    persist(next, activePlanId)
    set({ plans: next })
    return 'added'
  },
  removeProductFromPlan: (planId, productId) => {
    const next = get().plans.map((item) => {
      if (item.id !== planId) return item
      const productIds = item.productIds.filter((id) => id !== productId)
      const coverProductId =
        item.coverProductId === productId ? productIds[0] : item.coverProductId
      return { ...item, productIds, coverProductId, updatedAt: new Date().toISOString() }
    })
    persist(next, get().activePlanId)
    set({ plans: next })
  },
  advanceStage: (planId) => {
    const current = get().plans.find((item) => item.id === planId)
    if (!current || !canAdvanceStage(current)) return false
    const stage = nextStage(current.stage)
    if (stage == null) return false
    const next = get().plans.map((item) =>
      item.id === planId ? { ...item, stage, updatedAt: new Date().toISOString() } : item,
    )
    persist(next, get().activePlanId)
    set({ plans: next })
    return true
  },
  reset: () => {
    persist([], null)
    set({ plans: [], activePlanId: null })
  },
}))

export function selectActivePlan(state: PlanState): Plan | undefined {
  if (state.activePlanId == null) return undefined
  return state.plans.find((item) => item.id === state.activePlanId)
}

export function selectPlanById(state: PlanState, planId: string): Plan | undefined {
  return state.plans.find((item) => item.id === planId)
}

      if (value === '' || value == null) return null
      return typeof value === 'string' ? value : JSON.stringify(value)

)

function App({ children }: PropsWithChildren<any>) {

## M3 行为

- 新建方案时按面积生成预算：`totalFen = round(areaM2 * 80000)`（800 元/㎡）。不手填总额。
- 家具占用 = 当前方案内商品 `priceFen` 之和。收藏未加入方案的商品不计。材料 35%、人工 25%、其他为剩余且不小于 0。
- 预算页展示总额、四类目占用条（百分比封顶 100%）、阶段进度（量房 15 / 设计 40 / 施工 75 / 验收 100）。家具超过总额时该类目条满格，总额旁显示「已超支」。
- 无当前方案时空态「还没有当前方案」+「去方案看看」。
- 「收藏中有 N 件尚未加入当前方案」在 N>0 时出现，点击跳转「我的」；全部加入后消失。
- 方案详情增删商品后切回预算 Tab，家具占用立即变化。切换当前方案，预算跟着变。
- 「我的」提供「重置 mock」：清除 `fd:favorites` / `fd:plans` / `fd:budgets` / `fd:scans`，商品 mock 不受影响。
- 预算写入 Taro storage，key 为 `fd:budgets`。
